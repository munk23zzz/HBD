📖 Cara Kalibrasi Manual & Mengatur Kemiringan

  1. Drag kotak warna di canvas untuk menggeser posisi (X/Y) slot.
  2. Drag sudut kanan bawah (titik putih) untuk merubah ukuran (W/H).
  3. Isi kolom Rotasi (°) dengan angka positif (miring searah jarum jam) atau negatif (miring berlawanan). Contoh: 10 atau -12.
  4. Sesuaikan kotak sampai pas menutupi area foto polaroid pada template.
  5. Klik tombol 📋 Copy ke Clipboard.
  6. Buka file script.js → cari bagian slots: [ ... ].
  7. Paste kode baru tersebut menggantikan isi `slots` yang lama.
  8. Simpan file `script.js` dan refresh `index.html` untuk menguji hasilnya!

Tips Tambahan:
  • Gunakan tombol panah keyboard di input angka untuk fine-tuning per piksel / derajat.
  • Jika ada sisa warna latar polaroid di atas/bawah, sesuaikan nilai Y, H, atau Rotasi (°).
